# Database Engineering Lab

Small, runnable exercises for the database topics that show up in backend/data/ML interviews.

## PostgreSQL topics

- B-tree and GIN indexes
- `EXPLAIN` / `EXPLAIN ANALYZE`
- transactions and ACID
- isolation levels
- row locks and deadlocks
- connection pooling
- partitioning
- materialized views
- JSONB
- OLTP vs OLAP
- replication concepts

## Design rule

Each example explains the trade-off, not just the syntax.
